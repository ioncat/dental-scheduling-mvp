## 2. Layout / Centered Mode (Story 12.3)

### 2.1 Настройки Layout
- [ ] Settings → System → Layout → переключить на **Centered**
- [ ] Нажать **Save Changes**
- [ ] Проверить, что рабочая область сужается до указанной ширины
- [ ] Переключить Max Width: **1400 / 1600 / 1800** — каждый раз визуально сужается/расширяется
- [ ] Включить **Rounded corners** → углы скругляются
- [ ] Включить **Glass effect** → контент становится полупрозрачным с размытием фона
- [ ] Выключить Glass → контент снова непрозрачный, сайдбар остаётся тёмным
- [ ] Переключить обратно на **Full Width** → всё как было, на весь экран

### 2.2 Фон
- [ ] В Centered mode: Background Type → **Solid Color** → выбрать цвет → виден за "окном" приложения
- [ ] Переключить на **Image URL** → вставить URL картинки → фон меняется
- [ ] Нажать кнопку **Upload** (иконка стрелки вверх) → выбрать картинку с диска → фон из файла
- [ ] Нажать **X** (очистить) → фон убирается
- [ ] Проверить, что при переключении между Color и Image **значения не теряются** (вернуть обратно — прежнее значение на месте)
- [ ] Проверить Save Changes → перезагрузить → настройки сохранились

### 2.3 Edge Cases — Layout
- [ ] На мониторе < 1400px centered mode не должен отличаться от full width
- [ ] Glass effect: сайдбар **всегда** остаётся непрозрачным тёмным (не стеклянным)
- [ ] При выключенном glass правая граница "окна" видна (border + shadow)
- [ ] Layout настройки disabled в Full Width mode (dropdown, checkbox, фон — всё серое)

## 5. Создание назначения — Smart Flow (Story 5.7, 5.8)

### 5.1 Переключатель потока (Doctor-first / Patient-first)
- [ ] На странице Schedule нажать **"+ New Appointment"**
- [ ] Модалка открывается с заголовком "New Appointment"
- [ ] Вверху два переключателя-пилла: **"Doctor first"** (активен по умолчанию) и **"Patient first"**
- [ ] Нажать "Patient first" → видно поле "Patient" с кнопкой "Select patient..."
- [ ] Нажать "Doctor first" → возвращается поле "Doctor" (выбор пациента сбрасывается)
- [ ] Клик по **свободному слоту в расписании** → модалка открывается **без** переключателя (doctor pre-filled)

### 5.1a Doctor-first flow (шаг 1)
- [ ] **Doctor** — дропдаун с докторами из БД
- [ ] Выбрать врача → появляются:
  - [ ] **Suggested Slots** (⚡) — до 3 ближайших свободных слотов (дата + время)
  - [ ] **Select Day** — 7 пиллов (MON-SUN) с навигацией по неделям (< >)
  - [ ] **Available Times** — чипы со свободными слотами
- [ ] Клик по suggested slot → подсветка, выбранная дата переключается
- [ ] Клик по дню → слоты обновляются для выбранного дня
- [ ] Навигация по неделям (< >) → пиллы перезагружаются
- [ ] Сегодняшний день отмечен рамкой
- [ ] Выбранный день — заливка primary цветом
- [ ] Кнопка **"Next — Patient Details"** disabled пока не выбран слот
- [ ] Выбрать слот → кнопка становится активной → нажать

### 5.2 Шаг 2: Пациент + подтверждение
- [ ] Заголовок меняется на "Patient Details"
- [ ] Вверху ссылка **"← Back to time selection"** → возврат на шаг 1 (выбор сохраняется)
- [ ] **Сводка**: дата полностью (Saturday, April 4, 2026) + время (10:00 — 11:00)
- [ ] **Patient** — кнопка "Select patient..." → открывает модалку выбора пациента
- [ ] Выбрать пациента → имя отображается в кнопке
- [ ] **Notes** — поле для заметок (необязательное)
- [ ] Кнопка **"Create Appointment"** disabled пока не выбран пациент
- [ ] Выбрать пациента → нажать Create → назначение создано → модалка закрывается
- [ ] Новое назначение видно в расписании на выбранную дату

### 5.2a Patient-first flow
- [ ] Нажать "Patient first" в переключателе
- [ ] Нажать "Select patient..." → открывается модалка выбора пациента (поиск, таблица)
- [ ] Выбрать пациента → кнопка показывает имя с инициалом-аватаром
- [ ] Появляется селектор **Doctor** → выбрать врача
- [ ] Появляются **Suggested Slots**, **Select Day**, **Available Times** — как в doctor-first
- [ ] Кнопка **"Next — Confirm"** (не "Patient Details")
- [ ] Выбрать слот → нажать Next → шаг 2: "Confirm Appointment"
- [ ] Summary показывает дату, время, **Patient: [имя]**
- [ ] **Нет** поля выбора пациента (уже выбран на шаге 1)
- [ ] Есть поле Notes + кнопка Create Appointment
- [ ] Создать → назначение появляется в расписании

### 5.3 Просмотр назначения (View Mode)
- [ ] Клик по существующему назначению в расписании → модалка "Appointment Details"
- [ ] Отображается: статус (badge), врач, пациент, время, заметки
- [ ] Для `scheduled`: кнопки **Complete** и **Cancel Appointment**
- [ ] Cancel → подтверждение → статус меняется на `cancelled`
- [ ] Complete → статус меняется на `completed`
- [ ] Для `completed`/`cancelled` → кнопки действий не отображаются

### 5.4 Edge Cases — Appointments
- [ ] Создать назначение → попробовать создать ещё одно на то же время → слот должен быть занят (не отображаться в Available Times)
- [ ] Открыть модалку создания → не выбирать врача → пиллы и слоты **не отображаются**, только дропдаун
- [ ] Выбрать день без доступности → сообщение "No available slots for this day"
- [ ] Клик по времени в расписании (time grid) → модалка открывается с предзаполненными датой/временем

### 5.5 Suggested Slots
- [ ] При выборе врача с доступностью → Suggested Slots показывает до 3 слотов
- [ ] Слоты из будущего (не из прошлого — сегодняшние прошедшие слоты отфильтрованы)
- [ ] Клик по suggested slot → дата и слот выделяются в пиллах и чипах
- [ ] Если у врача нет доступности → секция Suggested Slots не отображается

### 5.6 Hover-подсветка и тултипы в расписании
- [ ] Навести мышь на **доступный слот** (белая зона, рабочие часы) → голубая подсветка + тултип **"10:00 — Click to book"**
- [ ] Навести мышь на **зону вне рабочих часов** (серая зона) → серая подсветка + тултип **"08:30 — Outside working hours (10:00–15:00)"**
- [ ] Навести мышь на слот с **существующей записью** → тултип **"11:00 — Booked: Іван Петренко"**
- [ ] Навести мышь на **time-off** → тултип **"14:00 — Vacation"** (или Sick leave / Blocked)
- [ ] Если у врача **нет рабочих часов** в этот день → тултип **"08:30 — No working hours today"**
- [ ] Клик по **недоступному** слоту → ничего не происходит (модалка не открывается)
- [ ] Клик по **доступному** слоту → открывается модалка с предзаполненным временем
- [ ] При уходе мыши с колонки → подсветка и тултип исчезают
- [ ] Тултип не появляется при наведении на **appointment block** (карточку записи)
