# Короткий отчет по репозиторию dental-scheduling-mvp

Дата обзора: 2026-04-03.

## Что это за проект
- Это MVP-платформа для расписания стоматологической клиники, задуманная как замена Google Calendar для ежедневных операций клиники.
- Репозиторий совмещает продуктовую документацию (discovery → scope → roadmap), системный дизайн и рабочую реализацию.

## Текущее состояние
- MVP заявлен как завершенный: реализовано 28/28 user stories.
- В покрытии есть ключевые процессы: управление персоналом, жизненный цикл пациентов, расписание приемов, контроль доступности и RBAC через Supabase RLS.

## Архитектура и стек
- Frontend: React + TypeScript + Vite + Tailwind + shadcn/ui.
- Backend-платформа: Supabase (Auth, Postgres, RLS, SQL-триггеры), без отдельного кастомного backend-сервиса.
- Проект документирован «контрактно»: бизнес-правила и lifecycle описаны в отдельных артефактах и поддержаны SQL-ограничениями/триггерами.

## Как быстро запустить
1. Развернуть схему БД через `docs/backend/init-all.sql` в Supabase SQL Editor.
2. В `app/.env` прописать `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
3. Запуск: `npm install && npm run dev` (или `docker compose up --build`).

## Сильные стороны
- Четкая связка «продуктовые решения → архитектура → исполнимая реализация».
- Детализированные документы по эпикам, ограничениям и решениям (включая осознанные исключения из MVP).
- Готовый demo seed для быстрого pilot/UX-валидационного прогона.

## Риски / что проверить в первую очередь
- Реальная эксплуатация на 1–3 пилотных клиниках (как и запланировано в документации) для проверки фактической адопции.
- Нагрузочные сценарии расписания и устойчивость UX при росте объема данных.
- Процедуры сопровождения: мониторинг, инциденты, backup/restore и операционная поддержка (в документах это не центральный фокус MVP).
